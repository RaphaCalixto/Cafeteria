# 🌿 Jardim Secreto • Beco do Café Artesanal

> Uma experiência web cinematográfica e imersiva para uma cafeteria escondida em um jardim botânico. Criada com **Next.js (App Router)**, **GSAP ScrollTrigger**, **Framer Motion** e design editorial anti-"AI slop".

![Preview do Banner](public/images/green-door-tunnel.jpg)

---

## ✨ Destaques da Experiência

- 🚪 **Banner Principal com Scrollytelling Cinemático:**
  - **Ato I — O Beco Botânico:** Câmera avançando pelo corredor de heras e flores em direção à porta verde com iluminação âmbar.
  - **Ato II — Abertura da Porta & O Salão:** A porta se abre fisicamente no vídeo com o scroll do usuário, revelando a cafeteria em luz quente e a copy *"Ao cruzar o portal, o tempo desacelera."*
  - **Ato III — Clímax Sensorial:** Foco na mesa com xícara de café especial com crema aveludada, vapor sutil e sobremesa artesanal confeitada.
- ☕ **Cardápio Bento Grid Editorial com Fisionomia Assimétrica:**
  - Cards de proporções e layouts variados (*Hero, Tall, Wide, Standard e Compact*).
  - Notas de degustação sensorial (acidez, doçura e intensidade).
  - Filtros interativos por categoria com animação fluida (*Framer Motion*).
  - Modal/Lightbox detalhado para cada prato e bebida com sugestão de harmonização da chef.
- 📸 **Galeria de Fotos da Casa:**
  - Exibição de momentos da torra artesanal, do pátio com jabuticabeiras e dos baristas com visualização em Lightbox.
- 📍 **Horários, Filosofia & Acesso:**
  - Guia de como encontrar o portal secreto no beco, horários da semana, comodidades (*Pet Friendly, Wi-Fi, Torra Própria*) e botão para contato via WhatsApp.

## 🛠️ Stack Tecnológica

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Animações de Scroll:** [GSAP](https://gsap.com/) + ScrollTrigger + `@gsap/react`
- **Microinterações & Modais:** [Framer Motion](https://www.framer.com/motion/)
- **Ícones:** [Lucide React](https://lucide.dev/)

## 🚀 Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/RaphaCalixto/Cafeteria.git
   cd Cafeteria
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   [http://localhost:3000](http://localhost:3000)

---

## 📦 Build para Produção

```bash
npm run build
npm run start
```
